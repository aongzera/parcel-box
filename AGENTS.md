# Smart Parcel Box

Embedded System Lab final project: an STM32 + ESP32-S3 parcel box that detects Deliveries and Collections and alerts the Owner. Read `product.md` (the project overview), `GLOSSARY.md` and `docs/adr/` before working.

## CI

`.github/workflows/ci.yml` runs on every push to `main` and on every PR. It has four jobs:
- `make test` from the repo root runs the Box logic core tests on a PC (one binary per `stm32/BoxCore/Tests/test_*.c`). Keep that command as the entry point.
- The STM32 firmware must build with `make -C stm32` (Ubuntu's `gcc-arm-none-eabi`). `stm32/` is an STM32CubeIDE project generated by CubeMX from `stm32/parcel-box.ioc`; `stm32/Makefile` is the command-line/CI build of the same folders (Core, Drivers, BoxCore minus BoxCore/Tests, as in `.cproject`). Our code builds with `-Wall -Wextra -Werror`; ST's drivers and template files are used as shipped.
- In CubeMX-generated files (`main.c`, `stm32f4xx_hal_msp.c`, `stm32f4xx_it.c`, `main.h`, ...) put every hand-written line inside a `/* USER CODE BEGIN … */ … /* USER CODE END … */` block, or the next code generation from the `.ioc` deletes it. Prefer new code in its own files (like `board.c`, `serial.c`). Change pins in the `.ioc` and `docs/pinmap.md` together.
- The ESP32 project in `esp32/` must build, using `secrets.example.h` as placeholder secrets.
- The build fails if any `secrets.h` is committed.

Jobs whose project doesn't exist yet skip themselves.
